# Project guide

## Purpose and deployment

Strength is a progressive web app for strength training. The intended stack is vanilla TypeScript, HTML, and CSS, without a frontend framework. The production site is hosted on GitHub Pages at <https://www.strength.berdalsanner.no>.

The repository is currently an early static-app scaffold. Consult `README.md` for local preview and GitHub Pages publishing notes; keep deployment assumptions aligned with the configured custom domain.
